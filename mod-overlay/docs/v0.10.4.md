# ShareX-Mod v0.10.4-dev — Safer Pagination Intent

This update removes the broad `text.Contains("next")` pagination heuristic from Capture Recipe compilation and then hardens the remaining exact-match path against generic Next controls.

## Why

A demonstrated click whose label contains the word `next` is not necessarily page navigation. Examples such as `Next.js`, `Next comment`, `Next image`, a carousel's `Next` button or a wizard's `Next` step can be legitimate controls and must not become an unattended `NextPage` step.

## High-confidence evidence

The classifier accepts pagination only when it has stronger page-specific evidence:

- a `rel` token exactly equal to `next`;
- an interactive control with an explicit normalized page label such as `Next page`, `Go to next page`, `下一页`, `下一頁`, `次のページ`, `다음 페이지`, `Page suivante`, `Nächste Seite` or `Página siguiente`;
- an explicit normalized identifier such as `pagination-next`, `pager-next`, `page-next` or `next-page`.

Punctuation and arrow glyphs around an otherwise explicit page label are normalized away, so `Next page ›` and `下一页 ›` remain valid.

## Deliberately rejected

Bare or generic signals are not enough: `Next`, `Go next`, `next`, `btn-next`, `button-next`, `Suivant`, `Weiter`, `Siguiente`, `次へ` and `다음` remain ordinary demonstrated actions unless stronger page semantics are present. This is intentionally conservative because these labels are common in carousels, onboarding, galleries and multi-step forms.

The regression suite includes both explicit pagination positives and false-positive traps where generic `next` identifiers are attached to image/wizard controls.

## Why `rel=next` is strongest

The HTML Living Standard defines `rel=next` as a link to the next logical document in a sequence, so it is treated as the strongest portable signal. A site with only a bare arrow or ambiguous Next button is not guessed into unattended pagination; Capture Recipe keeps it as an ordinary semantic action for review.

## Release-readiness checks

The current integration gate now also runs deterministic visual integrity tests for fixed/sticky edge-overlay repair and native-pixel appendix slicing, then reruns the complete self-test suite against the exact `ShareX.ScreenCaptureLib.dll` extracted from the generated portable archive before that artifact is uploaded.

# ShareX-Mod v0.4.1-dev

Focus: browser long-capture correctness before adding more automation.

- Browser capture does not require a Chrome/Edge extension. The previous companion-extension experiment has been removed.
- Robust primary matching ignores a larger side margin, requires a stronger exact-row run, and cross-checks candidate growth against independent frame motion.
- Anchor matching rejects patches that remain nearly unchanged at the same screen position, reducing false matches from fixed/sticky page UI.
- Fallback matching scores only tiles that actually move between frames and remains append-only for normal downward scrolling.
- Smart segmentation continues to bound working-image height, but all parts are streamed back into one `capture-full.png`.
- When browser-aware high-resolution image extraction is available, appendix images are rendered as tail pages and appended to the segmented capture before the final PNG is rebuilt.

The browser-aware transport remains optional. Generic ShareX scrolling capture and all stability fixes work without browser integration.

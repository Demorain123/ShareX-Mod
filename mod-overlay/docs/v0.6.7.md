# ShareX-Mod v0.6.7-dev — semantic range anchors and resumable automation

v0.6.7 moves Capture Recipe boundaries away from being purely absolute document-Y coordinates.

## Semantic range anchoring

During demonstration, document scroll observations retain a semantic content element near the upper viewport. The compiler uses the first/last useful anchors around a vertical coverage range and records:

- a semantic start locator;
- the recorded start-boundary offset from that locator;
- a semantic end locator encoded in range evidence;
- the recorded end-boundary offset from that locator;
- the original absolute Y values as fallback evidence.

During replay, both anchors are independently re-resolved. The current anchor position plus the recorded local offset becomes the new capture boundary. Absolute Y is used only on the side whose anchor cannot be resolved uniquely.

A sanity gate rejects implausible range-length changes and falls back to the original range rather than trusting an obviously wrong locator.

This lets a partial Start/Stop capture follow content when material above the range changes height between recording and replay.

## Resume journal

Long-running Recipe automation has an atomic `resume-journal.json` foundation. The journal records Recipe SHA-256, output directory, current/next step, page identity, existing parts, actions, dynamic-feed captured end, known document end, step count and unchanged-pass count.

Resume is disabled by default. When enabled, it is accepted only when:

- the Recipe hash is unchanged;
- the journal/output directory still exists;
- all recorded part files still exist;
- the previous run did not end in an unresolved in-flight action/navigation state.

An interrupted Next Page action is never blindly clicked a second time. It is marked for review unless page-state reconciliation can prove the transition state.

## Why anchors and resume belong together

A resume point is only useful if the remaining capture boundaries can survive a page whose layout has shifted since the prior run. Semantic anchors make the continuation less dependent on stale absolute coordinates; the journal prevents already completed ranges from being needlessly re-captured.

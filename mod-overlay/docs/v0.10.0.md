# ShareX-Mod v0.10.0-dev — Semantic Capture Recipe Router

v0.10.0-dev is the first milestone where the long-capture automation path is treated as a semantic capture state machine rather than mouse/scroll replay.

## What is now implemented

- Original ShareX scrolling capture remains available with manual Start / Stop.
- Capture Recipe recording stores semantic element evidence and demonstrated content ranges rather than relying on raw pointer coordinates.
- Same-URL SPA pagination is preserved as separate recorded page instances when a demonstrated Next Page action forms a boundary.
- Simple Page Loop requires two demonstrated pages with the same simple topology before it can be offered.
- Adaptive Page Template supports a recurrent single-family page structure.
- Template Router supports multi-family demonstrations such as A / B / A / C.
- The Router probes the current DOM on every page and only selects a family when the semantic score and uniqueness gap are both sufficient.
- Ambiguous or missing required family evidence stops automation and records a needs-review boundary; it never falls back to blind historical coordinates.
- Every multi-page path remains separately SHA-bound to Recipe review / page-loop approval.

## Capture quality stack

- semantic range-anchor re-resolution before capture;
- adaptive browser stability waiting;
- Page Guard revalidation before leaving a page;
- local stale-range recapture and evidence archive;
- infinite-feed Rolling Guard with delayed revalidation;
- per-page / periodic native image preservation before DOM virtualization can discard resources;
- horizontal sweep capture with appendix output;
- committed-boundary resume journals;
- cycle detection and bounded page / step / time limits;
- Position Ledger and final quality summary.

## Resume safety

A committed page boundary can be resumed. An ambiguous in-flight Next Page boundary cannot: the journal is marked `needs-review` so a retry cannot accidentally click Next twice.

Manual Stop preserves a resumable boundary instead of pretending that a paused capture is permanently complete.

## Chrome connection model

Chrome Enhanced automation is still opt-in. The dedicated Capture Browser uses a separate persistent user-data directory and loopback DevTools connection. The system does not claim to silently attach remote debugging to a user's normal default Chrome profile.

## CI baseline

The active integration gate replays the overlay chain, restores/builds ShareX Release x64, creates the portable package, validates required portable contents and uploads the artifact. Historical ShareX-Mod migration workflows are preserved under `.github/workflows-archive/` so they do not compete with the current gate on every push.

## Still intentionally conservative

Template-family selection currently relies primarily on semantic actionable locators. If two families differ only by layout/range geometry and expose indistinguishable semantic actions, the Router will report ambiguity and stop. Future work can add range-anchor evidence to family selection without weakening the fail-closed rule.
